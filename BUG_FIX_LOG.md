### Key Architectural Learnings
1. **Defensive Data Ingestion**: Real-world academic datasets frequently contain unexpected casing, whitespace, duplicate rows, and varying file extensions. The ingestion pipeline must sanitize headers and values immediately upon reading.
2. **Explicit User Intent in File Uploads**: Always provide a dedicated, visible action button for file uploads so users clearly understand what action triggers data ingestion.
3. **Deterministic UI State**: The state machine of the grading workflow should flow sequentially: Upload File -> Select Course -> Configure Ranges -> Validate -> Export. Transitioning between courses or re-uploading must clear stale caches completely.
4. **Graceful Fallbacks in Statistical Visualizations**: Normal distribution curves and standard deviations require guarding against edge cases like $N=1$, identical scores ($\sigma=0$), or empty selections to prevent browser math failures ($NaN$, $\pm\infty$).
