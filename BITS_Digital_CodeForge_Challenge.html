Marks file format guidance

The uploaded Excel file should contain exactly three columns: BITS ID, Course, and Total Marks.

Total Marks should be entered as whole numbers (0–100 scale). Fractional values will be rounded to the nearest integer.

Students who did not appear for the examination and are to receive an NC grade should not be included in the file.
